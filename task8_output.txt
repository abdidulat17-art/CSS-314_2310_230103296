=== Verdict ===
Non-tiled 154.5 ms | 16x16 1273.3 ms | 64x64 119.2 ms at 2 thread(s).
Fastest of the three: 64x64 tiles. Small tiles (16x16) keep data in L1 but pay for 262,144 tile calls;
64x64 tiles amortize call overhead (4,096 tile calls) while their working set still fits in L2.
Thread scaling (1 -> 2): non-tiled 1.71x, 16x16 0.90x, 64x64 0.89x, BLAS reference 2.26x.
The tiled kernels run a Python loop around many small NumPy calls that hold the GIL, so extra threads add
little; long GIL-free calls (row-wise dot, BLAS) scale with the cores. Tiling helps cache reuse, not Python overhead.
